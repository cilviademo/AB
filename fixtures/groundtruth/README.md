# Ground-truth fixture (SPEC §12)

A small JUCE plugin **with source**, so every recovery claim can be scored against an answer key.

| Piece | Where |
|---|---|
| Parameters (bool, enum, gain, cutoff, drive, oversample, output) | `spec.json` → `Source/GeneratedParams.h` (generated) |
| State-only decoys (`waveShapers_0_1` indexed field, `uiScale`) | `spec.json` → serialized in the ValueTree, never exported |
| TPT one-pole filter, normalised `tanh` waveshaper | `Source/Dsp.h` |
| `juce::dsp::Oversampling` 2× toggle | `Source/PluginProcessor.cpp` |
| Embedded PNG, TTF, preset XML (BinaryData) | `Resources/`, `Presets/` |
| PROTECTED_SUBSYSTEM-style stub | `Source/LicenseStub.h` |
| Answer key | `truth.json` (generated by `gen.py`, `artifactbench.ground_truth`) |

Build: `build_all.ps1` (Windows: Debug+PDB, Release+PDB, Release stripped) or `build_all.sh`
(Linux/macOS mirror). Outputs land in `out/<variant>/` and are CI artifacts, never committed.
Score a bundle: `ab-cli ground-truth <job_id>` → `GROUND_TRUTH_REPORT.json`.
